# Elmo Pull Tracker 0.2.2

**Elmo Pull Tracker** is a Windows pull tracker for Girls’ Frontline 2: Exilium. A fork of [ElmoBeacon](https://github.com/MatchaCabin/ElmoBeacon).

View your procurement history, banner pity, copy costs, and outfit records.

Download **ElmoPullTracker-0.2.2-windows-x64.zip**. Close the old app, back up `ElmoBeacon.db`, and put `ElmoPullTracker.exe` in the same app folder to keep your history and settings. Existing valid capture certificates are reused.

Capture is built in; no Fiddler or separate capture tool is needed. Root certificate trust is removed after successful import by default.

The executable is unsigned. Regional testing remains incomplete. Matching source and SHA-256 checksums are included under GPL v3.
